# P1 基建验证记录

日期：2026-10-20

## 范围

P1 只交付可运行的单体应用骨架，不包含业务 CRUD：

- Next.js App Router 路由组：公开站点 `app/(site)`、后台 `app/(admin)`，根布局只保留 `<html>/<body>`。
- SQLite/Drizzle 运行时连接：懒加载、自动创建数据目录、WAL/foreign_keys/busy_timeout 等 PRAGMA。
- 环境变量校验：`server/env.ts`（`DATABASE_PATH`、`SITE_READ_ONLY`、`AUTH_SECRET` 等）。
- 管理员认证：bcrypt 密码、HS256 JWT、httpOnly `kir_admin` Cookie、登录/登出/当前用户/改密 API。
- 统一 API 错误信封、`requestId`、结构化请求日志、登录失败限流、同源写入校验。
- 后台空壳：`/admin/login`、受保护的 `/admin` 仪表盘、侧边栏、退出登录。
- 管理员 seed 脚本：不内置默认密码。
- CI：安装、类型检查、单测、空库迁移、生产构建。

## 已验证

### 空库、迁移、管理员

```bash
DATABASE_PATH=/tmp/kirameku-p1/kirameku.db pnpm db:migrate
DATABASE_PATH=/tmp/kirameku-p1/kirameku.db \
  ADMIN_USERNAME=admin \
  ADMIN_PASSWORD='P1-test-password-42' \
  ADMIN_NICKNAME='测试站长' \
  pnpm db:seed-admin
```

结果：

- `0000_initial.sql` 首次应用，创建 20 张非 `sqlite_*` 表。
- `integrity_check` 通过，`foreign_key_check` 为空。
- `auto_vacuum` 为 `incremental`。
- `db:seed-admin` 创建管理员成功；重复执行会更新该用户名密码。
- 没有默认管理员密码；`ADMIN_PASSWORD` 少于 12 字符或超过 bcrypt 72 字节会被拒绝。

### API 与后台（临时数据库 + `pnpm dev --port 3100`）

| 请求 | 结果 |
|:---|:---|
| `GET /api/health` | `200 {"ok":true,"db":"ok","migration":"0000_initial.sql"}` |
| `POST /api/auth/login` 错密码 | `401 UNAUTHORIZED`，错误信息不区分用户不存在/密码错误/非管理员 |
| `POST /api/auth/login` 正确密码 | `200`，设置 `kir_admin`（HttpOnly、SameSite=Lax；生产加 Secure） |
| `GET /api/auth/me` 带 Cookie | `200`，返回不含 `hashedPassword` 的管理员资料 |
| `GET /api/auth/me` 无 Cookie | `401` |
| `GET /admin` 未登录 | `307` 到 `/admin/login` |
| `GET /admin` 已登录 | `200`，显示仪表盘 |
| `GET /admin/login` 已登录 | `307` 到 `/admin` |
| 跨站 `Origin` 登录 | `403 FORBIDDEN` |
| `POST /api/auth/change-password` 错旧密码 | `400` |
| `POST /api/auth/change-password` 正确旧密码 | `200 {"ok":true}`；新密码可登录 |
| `POST /api/auth/logout` 后 `me` | `401` |

登录失败按 IP 计入固定窗口，5 次/分钟后拒绝；成功登录不消耗失败额度。

## 本地启动

```bash
cp .env.example .env.local
# 编辑 .env.local：至少设置 AUTH_SECRET（32+ 字符）和 DATABASE_PATH
pnpm db:migrate
ADMIN_USERNAME=admin ADMIN_PASSWORD='至少12位的强密码' pnpm db:seed-admin
pnpm dev
```

后台：`http://localhost:3000/admin/login`

> `AUTH_SECRET` 未配置时，公开页面仍可构建；登录/会话接口会返回 500。生产环境必须配置。

## 资源使用说明

本次验证过程中曾多次启动 `next dev` 与 `next build`，在 macOS 上产生较多 Turbopack 工作进程。后续验证约定：

- 不并行启动多个 dev server / build。
- 验证完成后显式停止 dev server。
- 优先使用一次 `pnpm test` + 一次 `pnpm build`，避免反复全量编译。
