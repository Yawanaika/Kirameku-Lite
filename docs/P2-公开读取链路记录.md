# P2 公开读取链路记录

日期：2026-10-21

## 本轮完成

公开站点的文章读取链路已从旧 FastAPI 切到本地 SQLite：

| 接口 | 实现 |
|:---|:---|
| `GET /api/posts` | `app/api/posts/route.ts`，支持 `status`、`category`、`tag`、`page`、`size` |
| `GET /api/posts/count` | `app/api/posts/count/route.ts` |
| `GET /api/posts/[slug]` | `app/api/posts/[slug]/route.ts`，仅返回已发布文章 |
| `GET /api/posts/detail/[id]` | `app/api/posts/detail/[id]/route.ts`，仅返回已发布文章 |
| `POST /api/posts/[id]/like` | 本地点赞，保留 `{ likes }` 响应 |
| `POST /api/posts/[id]/unlike` | 本地取消点赞，保留 `{ likes }` 响应 |
| `GET /api/categories` | 本地分类列表，`post_count` 按已发布文章计算 |
| `GET /api/tags` | 本地标签列表，`post_count` 按已发布文章计算 |

服务层：

- `server/modules/posts/service.ts`：列表、详情、按 ID 查询、计数、点赞/取消点赞。
- `server/modules/categories/service.ts`：分类及已发布文章计数。
- `server/modules/tags/service.ts`：标签及已发布文章计数。
- `server/modules/site-stats/service.ts`：首页文章/说说/照片数量。

页面与 Feed：

- `/posts` 首屏改为服务端读取；分类筛选和加载更多仍在客户端完成。
- `/posts/[slug]` 首屏改为服务端读取，并增加 `generateMetadata`、404 页面；点赞、代码高亮、灯箱、目录和评论仍在客户端运行。
- 首页统计不再请求旧 FastAPI，直接查 SQLite。
- `/feed` 改为本地文章列表 + 详情，不再请求 `127.0.0.1:8000`。
- `PostCard` 与详情页日期固定按 `Asia/Shanghai` 格式化，并处理 SSR 文本差异。
- `next.config.mjs` 的旧 FastAPI 代理改为 `fallback` rewrites：本地静态/动态 Route Handler 优先，未迁移接口才回退到旧服务。

## 行为约定

- 公开 API 默认只返回 `published`，不会通过省略 `status` 暴露草稿；草稿查询参数会被校验拒绝。
- 文章详情 GET **不再自增浏览量**。详情页 SSR 和 prefetch 会放大计数，后续通过客户端上报 + 去重处理。
- 分类/标签的 `post_count` 不再依赖可能漂移的存储字段，而是按已发布文章实时聚合。
- 响应字段保持旧前端使用的 snake_case：`is_pinned`、`word_count`、`reading_time`、`published_at`、`post_count` 等。
- 点赞是公开写接口，但增加了只读模式检查和同源检查；限流/去重留到 P2 写入链路。
- 不存在的文章会渲染自定义 not-found 页面并输出 `noindex`。由于 Next 16 对动态页面采用流式响应，HTTP 状态可能是 200（soft 404）；这是 Next 已知行为，不是数据查询失败。

## 数据现状

当前 `data/kirameku.db` 只有 schema、迁移记录和管理员数据：

```text
post=0, category=0, tag=0, post_tag=0
```

因此页面会显示空状态，这是数据为空而不是接口失败。文章服务测试使用临时 SQLite 数据库和固定 fixture，覆盖分类/标签/分页/草稿隔离/点赞归零。

```text

```

Smoke test 使用临时 SQLite fixture，并在验证后立即关闭 production server。确认结果包括：

- `/api/posts`、`/api/posts/[slug]`、`/api/posts/detail/[id]` 返回 fixture；
- `/api/posts?status=draft` 返回 422；
- 点赞/取消点赞返回 `{ likes }` 且计数正确归零；
- `/posts/[slug]` SSR 输出文章标题；
- `/posts/missing` 输出自定义 404 页面和 `noindex`；
- `/posts`、`/feed` 返回 200。

当前 `.next` 构建使用空的内容表；正式部署前需要先导入/创建内容。
